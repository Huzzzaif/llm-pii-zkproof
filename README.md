# ZKPriv

Zero-knowledge receipts that an LLM response complies with a committed privacy policy.

**Two-tier guarantee**
1. *Structured PII* (SSN, email, phone, credit card + Luhn, IP, …) is detected **inside the circuit**: the proof shows no detector DFA ever accepts over the committed response bytes.
2. *Semantic PII* (names, addresses) is labelled by a TEE-attested classifier; the circuit verifies the enclave's signature over the labels.

Users receive the response, its commitment opening and a signed receipt, so a provider that serves PII to one user can be proven to have done so.

## Layout
| Dir | Contents |
|---|---|
| `circuits/` | Circuit source (detectors, commitment, policy, signature check) |
| `prover/` | Witness generation, proving/verification, benchmarks |
| `tee-sim/` | Simulated enclave: LLM call, NER labelling, signing |
| `eval/` | Datasets, LLM output collection, detector accuracy, adversarial cases |
| `paper/` | LaTeX source; every number is generated by a script in this repo |
| `docs/` | Design notes and threat model |
| `scripts/` | One-command reproduction |
